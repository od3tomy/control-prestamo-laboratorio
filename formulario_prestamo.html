¿Cómo conectar Google Sheets?
  1. Crea una hoja de cálculo en Google Sheets.
  2. Abre Extensiones → Apps Script y pega el archivo Code.gs.
  3. Ejecuta la función setup y copia el TOKEN y la URL de la hoja.
  4. Implementa como Aplicación web, ejecutar como tú y acceso Cualquier persona.
  5. Pega aquí la URL del Web App y el TOKEN, y pulsa Guardar conexión.
